# lfm3-vl 2B against the pipeline — hardest three cards

**Date:** 2026-11-03. **Model:** `lfm3-vl:2b-q8_0` in Ollama (1.7B parameters, Q8_0,
2.2 GB, 128k context; thinking disabled). **Cards:** form21, form22, form30 — the three
lowest routed scores on the seven-card set (87.5%, 78.8%, 94.0% at the 2026-10-29 route).

Same aligned cards, same block crops, same generated prompts, same JSON parser and the
same canonical comparison as `core.run`. The only change is the backend, so block numbers
are directly comparable with the ledger. One run at temperature 0.

## Results

150 scoreable values across eight blocks.

| block | lfm3-vl 2B | pipeline, latest run | current standard |
|---|---|---|---|
| general_demographic | 15/20 (75.0%) | 17/20 | 18/20 (9B) |
| classification | 7/9 (77.8%) | 9/9 | 9/9 (8B) |
| clinical_history | 15/18 (83.3%) | 17/18 | 17/18 (9B) |
| nerve_assessment | **34/36 (94.4%)** | 36/36 | 36/36 (MinerU) |
| skin_patch | 2/3 (66.7%) | 3/3 | 3/3 (8B) |
| hand_feet_assessment | **0/12 (0%)** | 10/12 | 11/12 (9B) |
| def_exam | 19/42 (45.2%) | 38/42 | 42/42 (MinerU) |
| treatment_follow | **1/10 (10%)** | 10/10 | 8/10 (8B) |
| **total** | **93/150 (62.0%)** | **140/150 (93.3%)** | **~146/150** |

Per card: form21 32/48 (66.7%), form22 32/52 (61.5%), form30 29/50 (58.0%).

"Pipeline, latest run" is the most recent completed run in the ledger for each card
(form21/form22 are 2026-11-01 box runs, form30 is the 2026-10-29 route). On `def_exam` and
the nerve grid the route now reads with MinerU, so the current standard is higher than the
latest-run column for form22 and form30.

Speed: 1.3–2.4 s per block, 47 s for all 24 blocks, no API cost.

## Where it does well

- **The nerve grid.** 34/36 without any table structure: it returned the twelve
  `+`/`-` values in the right positions, including the pluses on form21 (cubital left,
  popliteal right, pain cubital left) and form22. That is better than the 8B on the same
  crops (7/12 on form21) and close to MinerU's 36/36. A 2B model can read this grid; it
  does not replace the reader that reads it exactly.
- **JSON discipline.** Every one of the 24 calls returned parseable JSON in the requested
  key set, with no retries. The prompts were written for Qwen and were not shortened; a
  1.7B model following them is the strongest part of the result.
- **Clinical history and classification** are within two values of the pipeline.

## Where it fails

- **Disability table, 19/42.** It fills all fourteen keys, so the failure is wrong values,
  not missing ones: grades shifted by one eye (`3` where the card has `0`), lagophthalmos
  swapped with grades, muscle strength dropped on form22. The 27B gets 42/42 here and
  MinerU 42/42.
- **Hand/feet, 0/12.** It returns counts (4, 5, 1, 3 against 2, 1, 0, 2) and invents ulcer
  and amputation flags. A diagram with marks is not a text field.
- **Treatment grid, 1/10.** It answers the `dose_grid` JSON but the rows do not match the
  card; only form30's start date survived.

## Verdict

Not a routing candidate. The 2B is 31 points behind on these cards, and the gap is
concentrated exactly where the pipeline was already weakest — the tables and the diagram —
so it does not add a failure mode the reader covers.

It is a plausible **offline fallback** for demographics, clinical history and the nerve
grid if the box and the network are both unavailable: 75–94% on those three blocks, two
seconds a block, free, on a laptop. That is a different product decision from accuracy.

## Caveats

- One prompt family, written for Qwen 9B/27B. A shorter, task-specific prompt was tried on
  the two failing blocks: hand/feet rose from 0/12 to 3/12 with a four-line counting prompt,
  and the disability table did not improve — the compact prompt returned header letters
  (`D`, `E`, `N`, `F`) in the grade fields. Prompt tuning does not close these two gaps.
- One run per block, temperature 0. No repeat to estimate variance.
- The current-standard column mixes measured per-block bests (MinerU 2026-10-30, 9B and 8B
  from the 2026-10-27/29 runs); it is not a single run.
